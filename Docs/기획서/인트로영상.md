# 인트로 영상 (Intro Splash)

## 개요
- **작업 씬**: `Assets/Scenes/Intro.unity` (신규 생성, Build Settings 첫 번째 씬)
- **목적**: 게임 실행 시 메인 메뉴가 뜨기 전에 영상을 재생하고, 검정 화면 전환 후 메인 메뉴(`2 SCENE`)로 넘어감
- **영상**: `Assets/Videos/기지 상공 접근.mp4` (사용자 제공, 세로 720x1280, 길이 약 3초)

## 계층 구조 (Hierarchy)

```
Intro
├── Main Camera     (Camera, AudioListener, VideoPlayer, UniversalAdditionalCameraData)
│   └── VideoPlayer: clip=기지 상공 접근.mp4, renderMode=Render Texture, playOnAwake=true, isLooping=false
├── FadeCanvas      (Canvas Screen Space-Overlay, CanvasScaler)
│   ├── VideoImage  (RawImage + AspectRatioFitter, 화면 전체 stretch) — VideoPlayer의 RenderTexture를 표시
│   └── FadeImage   (Image, 화면 전체 stretch, 검정색, 시작 알파=0)
└── IntroManager    (IntroSequence 스크립트)
```

**URP 주의사항**: `VideoPlayer.renderMode = Camera Far/Near Plane`은 Built-in RP 전용 기능이라 URP에서는 아무것도 렌더링하지 않는다. 그래서 `Assets/Videos/IntroVideoRT.renderTexture`(720x1280, 영상 원본 해상도와 동일)를 만들어 VideoPlayer의 `targetTexture`로 지정하고, `FadeCanvas/VideoImage`의 `RawImage`가 그 RenderTexture를 화면에 그린다. `AspectRatioFitter`(`EnvelopeParent`, ratio 0.5625)가 기존 `FitOutside`와 동일하게 화면을 꽉 채우도록(좌우 약간 크롭) 처리한다.

## 동작 흐름
1. 씬 시작 시 `VideoPlayer`가 자동 재생 (`playOnAwake`), RenderTexture를 통해 `VideoImage`에 그려짐
2. 영상이 끝나면(`loopPointReached`) `IntroSequence.BeginTransition()` 호출 — **영상은 끝까지 재생됨** (중간에 강제로 끊지 않음)
3. `FadeImage`의 알파를 0→1로 1초에 걸쳐 서서히 올려 검정 화면 전환
4. 전환 완료 후 `SceneManager.LoadScene("2 SCENE")`으로 메인 메뉴 씬 로드

안전장치: `videoPlayer.errorReceived`로 로딩/재생 오류 시 즉시 스킵하고, 워치독 코루틴이 영상 길이 기준으로 타임아웃을 좁혀가며 어떤 이유로든 `loopPointReached`가 오지 않아도 씬이 무한 대기하지 않도록 보장한다(기본 상한 15초).

## 스크립트
- `Assets/Scripts/UI/IntroSequence.cs` (namespace `Zzinmak.UI`)
  - `videoPlayer`, `fadeImage`, `nextSceneName`("2 SCENE"), `fadeDuration`(1초), `safetyTimeout`(15초), `endMargin`(2초) 필드로 Inspector에서 조정 가능

## 에디터 편의 기능
- `Assets/Editor/PlayFromIntroScene.cs`: 메뉴 `Zzinmak/재생 시 항상 인트로부터 시작`(기본 켜짐)이 켜져 있으면, 에디터에서 어떤 씬을 열어두고 Play를 눌러도 항상 `Intro` 씬부터 시작한다(`EditorSceneManager.playModeStartScene`). 개발 중 Game 씬만 빠르게 반복 테스트하고 싶으면 이 메뉴를 꺼서 현재 씬에서 바로 재생할 수 있다. 설정은 `EditorPrefs`에 저장되어 에디터 재시작 후에도 유지된다.

## Build Settings
- 씬 순서: `Intro`(0) → `2 SCENE`(1) → `Game`(2)
- Intro가 0번이므로 빌드 실행 시 자동으로 가장 먼저 재생됨
- 에디터에서 Play 버튼은 기본적으로 **현재 열린 씬**에서 시작한다(빌드 인덱스와 무관) — 위 "에디터 편의 기능" 참고
