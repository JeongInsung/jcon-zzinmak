# 맵 건물/장식품 그림자 시스템

## 작업 일자
2026-07-30

## 배경
`Assets/Map/Map.prefab`은 SpriteRenderer 기반 2D 맵으로, URP 2D 렌더러(`Assets/Settings/Renderer2D.asset`)가 이미 설정되어 있었음. 건물/장식품에 입체감을 주기 위해 URP 2D 라이트 + Shadow Caster 2D 방식으로 실시간 그림자를 추가함.

## 변경 사항

### 1. `Assets/Map/Map.prefab`
- `Tilemap/buillding` 하위 모든 오브젝트(SpriteRenderer 보유) — 건물 전체
- `Tilemap/장식` 하위 오브젝트 중 이름이 `주차장`으로 시작하는 것을 제외한 나머지 — 장식품
- 위 대상들에 `ShadowCaster2D` 컴포넌트를 일괄 추가 (기본값: `useRendererSilhouette=true`, `castingOption=CastShadow`). 총 120개 오브젝트에 추가됨.
- **주차장 오브젝트(`장식/주차장`, `주차장 (1)~(4)` 등 6개)는 요청대로 제외** — 그림자 없음.
- `Tilemap/ground`(바닥/도로), `Tilemap/car`(차량)는 이번 요청 범위(건물/장식품)에 포함되지 않아 손대지 않음.

### 2. `Assets/Scenes/2 SCENE.unity`
- 씬에 라이트가 전혀 없어 그림자가 보이지 않으므로 `Global Light 2D` 오브젝트를 씬 루트에 추가.
  - `Light2D.lightType = Global`, `color = white`, `intensity = 1` (기존 밝기와 동일하게 유지)
  - `shadowsEnabled = true`, `shadowIntensity = 0.75`

## 참고 / 주의
- Sprite 머티리얼은 `Universal Render Pipeline/2D/Sprite-Lit-Default`라 Light2D 영향을 받음 (Unlit이면 그림자가 안 보임).
- Global Light2D 그림자는 광원 위치가 없어 "그림자가 특정 방향으로 길게 늘어지는" 연출은 아니고, 오브젝트 아래에 자연스러운 음영이 생기는 형태에 가까움. 태양처럼 방향성 있는 긴 그림자를 원하면 나중에 `Point Light 2D`를 맵 전체를 덮는 범위로 배치하는 방식으로 교체 검토 가능.
- 새로 추가되는 건물/장식품 오브젝트에는 자동으로 ShadowCaster2D가 붙지 않으므로, 이후 맵에 오브젝트를 추가할 때 수동으로 추가해야 함 (주차장 계열은 제외).
- 이번 작업의 자동 검증(Editor 스크린샷)은 Scene View/헤드리스 카메라 렌더링 경로에서 2D 라이트 갱신이 제대로 반영되지 않아 신뢰할 수 없었음. Unity 에디터에서 직접 Scene 뷰(Scene Lighting 켜짐) 또는 Play 모드로 확인 필요.
