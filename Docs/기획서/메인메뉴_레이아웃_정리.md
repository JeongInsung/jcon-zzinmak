# 메인메뉴 레이아웃 근본 수정

## 개요
- **작업 씬**: `Assets/Scenes/2 SCENE.unity`
- **제작 방식**: UGUI, Hierarchy에 실제 GameObject로 구성. 아래 수치는 모두 씬에 적용 완료됨.
- **왜 필요했나**: 메인메뉴만 `CanvasScaler` 기준 해상도가 `1920x1080`(가로)이었다. Game/Intro 씬은 둘 다 `1080x2340`. 그 어긋남을 메꾸려고 `MenuButtons` 스케일 1.1679, `SettingsPanel` 스케일 0.9058216, 설정 슬라이더 행 스케일 1.1856002 같은 **손으로 끼워맞춘 보정값**이 여기저기 붙어 있었다. 그 상태에서 기기 화면 비율이 1080x2340과 조금만 달라져도 배치가 깨졌다 — 그 결과로 [[설정창]]의 "알려진 이슈"(`BackButton` 위치 이탈)와, 문서에 없던 "설정" 제목 이탈, 딤 배경 틈, 크레딧 카드가 4:3에서 화면 밖으로 나가는 문제가 함께 발생했었다.

## 근본 수정: CanvasScaler 기준 해상도 통일

`Canvas` → Canvas Scaler → Reference Resolution: **`1920 x 1080` → `1080 x 2340`** 적용 완료 (Match 0.5는 그대로).

이 한 줄이 이후 모든 수치의 전제였다. 화면이 커지는 만큼 아래 보정을 함께 적용해 원래 크기를 유지했다.

| 오브젝트 | 항목 | 이전 | 현재 |
|---|---|---|---|
| `SettingsPanel` | localScale | 0.9058216 | **1** |
| `MenuButtons` | localScale | 1.1679 | **1** |
| `MenuButtons` | anchoredPosition | (0, -426) | **(0, -470)** |
| `MenuButtons` | sizeDelta | (480, 550) | **(620, 710)** |
| `MenuButtons` › VerticalLayoutGroup | Spacing | 40 | **52** |
| `StartButton`/`SettingsButton`/`QuitButton`/`CreditsButton` | sizeDelta | (0, 90) | **(0, 116)** |
| 위 4개 `Label` | Font Size | 36 | **46** |
| `SettingsButton/Icon` | sizeDelta | (48, 48) | **(62, 62)** |
| `QuitButton/Icon` | sizeDelta | (40, 40) | **(52, 52)** |
| `Title` | anchoredPosition | (0, -120) | **(0, -133)** |
| `Title` | sizeDelta | (900, 150) | **(994, 166)** |
| `Title` | Font Size | 110 | **121** |

`SettingsPanel`의 자식들(제목/라벨/슬라이더/토글)과 `MasterLabel` 등 행 스케일(1.1856002)은 스케일이 1로 돌아가는 것과 무관하게 픽셀 크기가 그대로 유지되므로 그대로 뒀다. `Background`, `FadeOverlay`, `CreditsPanel`(자기 자신)은 전체 스트레치라 변경 없음.

## 설정/크레딧 카드를 중앙 앵커로

좌상단 앵커 + x 좌표 하드코딩이 근본 원인이었으므로, 두 카드 모두 화면 중앙 앵커로 바꿨다.

| 오브젝트 | 항목 | 이전 | 현재 |
|---|---|---|---|
| `SettingsPanel/Panel` | Anchor Min/Max | (0,1)/(0,1) | **(0.5,0.5)/(0.5,0.5)** |
| `SettingsPanel/Panel` | anchoredPosition | (500, -815) | **(0, 0)** |
| `CreditsPanel/CreditsCard` | Anchor Min/Max | (0,1)/(0,1) | **(0.5,0.5)/(0.5,0.5)** |
| `CreditsPanel/CreditsCard` | anchoredPosition | (490, -1200) | **(0, 0)** |
| `CreditsPanel/CreditsBody` | Wrapping | NoWrap | **Normal(줄바꿈 켬)** |

## 설정창 "뒤로" 버튼 + 제목 위치 수정

[[설정창]]에 기록된 알려진 이슈(`BackButton`이 카드 밖 197px 아래)와, 문서에 없던 "설정" 제목이 카드 위 85px 밖에 뜨는 문제를 함께 고쳤다. 카드는 720x1170이라 카드 로컬 y가 -585 ~ +585다.

| 오브젝트 | anchoredPosition 이전 | 현재 |
|---|---|---|
| `Panel/controler` | (130, 50) | **(130, -80)** |
| `controler/BackButton` | (200, -1300) | **(200, -762)** |
| `Panel/SettingsTitle` | (350, 85) | **(350, -80)** |

`controler` 하나만 옮겨서 그 자식 8개(라벨 3 + 슬라이더 3 + 토글 2)가 통째로 따라가게 했다.

## SafeArea 추가

`Assets/Scripts/UI/SafeArea.cs`(기존, `Game.unity`에서 검증됨)를 재사용.

- `Canvas` 밑에 빈 GameObject `SafeArea` 추가 (Sibling Index 1, `Background` 다음), 전체 스트레치
- `SafeArea` 컴포넌트: Pad Top ✓ / Pad Bottom ✓ / Pad Left ✗ / Pad Right ✗
- `Title`, `MenuButtons`를 이 안으로 이동. `SettingsPanel`/`CreditsPanel`/`QuitConfirmPanel`/`FadeOverlay`는 전체 화면 오버레이이므로 Canvas 직속으로 유지.

## 뒤로가기 / 종료 확인 / 빠진 정보

`Assets/Scripts/UI/MenuBackHandler.cs`, `Assets/Scripts/UI/MainMenuInfo.cs` 신규 스크립트로 구현, 씬에 배선 완료:

- `Canvas`에 `MenuBackHandler` 부착 — `Closable Panels`: `SettingsPanel`, `CreditsPanel` / `Quit Confirm Panel`: 아래 `QuitConfirmPanel`
- `Canvas` 밑에 `QuitConfirmPanel` 신규 (구조는 `CreditsPanel`과 동일 — 백드롭 + 카드 + 메시지 + 예/아니오 버튼). `MenuButtons/QuitButton`의 onClick을 `MainMenuController.QuitGame` 대신 `QuitConfirmPanel`의 `UIPanelToggle.Open`으로 재배선. "종료" 버튼의 onClick이 실제 `MainMenuController.QuitGame`을 호출.
- `Canvas`에 `MainMenuInfo` 부착, `SafeArea` 밑에 `BestRecordText`/`VersionText` TMP 오브젝트 신규 — 씬 시작 시 플레이스홀더가 표시되고, `MainMenuInfo.OnEnable`이 `PlayerPrefs["BestSurvivalTime"]`과 `Application.version`으로 갱신함
- **`(제작자명)` 플레이스홀더는 그대로 남아 있음** — 실제 제작자 이름을 알아야 채울 수 있어 이번 작업에서 제외. `크레딧.md` TODO 참고

## 앞으로 이 씬에서 지킬 규칙
- **좌상단 앵커 + x 좌표 하드코딩을 쓰지 말 것.** 이번에 깨진 모든 요소가 이 패턴이었다. 중앙 정렬 요소는 (0.5,0.5) 앵커, 상단 고정 요소는 (0.5,1) 앵커를 쓴다.
- CanvasScaler 기준 해상도는 **항상 1080x2340**으로 Game/Intro와 통일한다.
- 새 패널을 추가할 때 `Title`/`SettingsPanel`/`CreditsPanel`/`FadeOverlay`에 남아있는 잉여 `VerticalLayoutGroup`(설정 없음, 자식은 `LayoutElement.IgnoreLayout=1`로 무시 중)을 건드리지 말 것 — 체크가 풀리면 카드 위치가 제멋대로 재배치된다.

## 검증 시 확인할 것
- 여러 해상도(1080x2340 / 1080x2400 / 1080x1920 / 4:3 태블릿)에서 Game view 확인 — 카드가 항상 중앙에 오고 화면 밖으로 나가지 않는지
- 설정창 딤 배경이 화면을 끝까지 덮는지, "설정" 제목과 "뒤로" 버튼이 카드 안에 있는지
- 뒤로가기(Escape 키, 에디터에서는 재현 안 됨 — **실기기 빌드 필수**): 설정/크레딧 열려 있을 때는 해당 패널만 닫히고, 아무 패널도 없을 때는 종료 확인창이 뜨는지
- 종료 확인창에서 "종료"는 앱 종료, "취소"는 확인창만 닫히는지
- 게임 플레이 후 메인메뉴 복귀 시 최고 기록이 갱신되는지
