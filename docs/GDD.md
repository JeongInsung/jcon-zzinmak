# Game Design Document — 좀비 아포칼립스 서바이벌 (가제)

## 1. 컨셉

- **장르**: 2D 탑다운 뱀서라이크(자동전투 생존)
- **세계관**: 좀비 아포칼립스가 발생한 도시. 플레이어는 파견된 **특수부대 군인**으로, 몰려오는 좀비 무리 속에서 정해진 시간 동안 생존해야 한다.
- **플랫폼**: 모바일(세로) — 해상도 **1080 x 2340**
- **핵심 판타지**: 밀려드는 물량의 좀비를 화력과 성장으로 압도하며 버텨내는 쾌감.

## 2. 핵심 루프 (Core Loop)

```
이동(조이스틱) → 좀비 접근 → 무기 자동 발사 → 좀비 처치
   → 경험치 젬 드롭/획득 → 경험치 누적 → 레벨업
   → 강화 카드 3택 → 전투력 상승 → (무한 반복, 난이도 지속 상승)
   → 체력 0(패배)까지 최대한 오래 생존 (기록 경신형)
```

- 플레이어는 **이동만** 직접 조작한다. 공격은 보유 무기가 자동으로 수행한다.
- 좀비는 시간 경과에 따라 스폰 빈도와 강도가 **무한히** 증가한다(웨이브 곡선에 상한 없음).
- **승리(엔딩) 조건은 없다.** 얼마나 오래 생존했는지가 곧 결과이며, 타이머는 경과 기록용으로만 표시한다.

## 3. 조작

- **가상 조이스틱**(화면 좌하단, 하이어라키 UI): 드래그 방향으로 이동.
- 에디터 테스트용: WASD / 방향키 폴백.
- 공격/조준: 자동(가장 가까운 좀비 우선).

## 4. 승패 조건

- **무한 생존**: 별도의 승리(엔딩) 조건 없이 난이도가 끝없이 상승하며 무한히 계속된다.
- **패배**: 플레이어 체력이 0이 되면 즉시 게임오버. 생존 시간/킬 수가 결과 기록으로 남는다.
- 타이머는 승패 판정용이 아니라 **생존 기록 표시(HUD)** 용도로만 사용한다.

## 5. 시스템 개요

### 5.0 맵 & 건물 미션
- 유한한 크기의 야외 맵 하나(40x40)를 사방 벽으로 막아 경계를 둔다.
- 게임 시작 시 맵 안 랜덤 위치에 **건물**이 하나 생성된다. 건물에 닿으면 내부(고정된 미니 전투장)로 이동.
- 건물 내부에는 정해진 수(기본 5마리)의 좀비와 인질 1명이 있다. 좀비를 전부 처치한 뒤 인질에게 닿으면 구출 완료 — 야외로 복귀하며 기존 건물은 사라지고 다른 랜덤 위치에 새 건물이 생성된다.
- 건물 안에 있는 동안 야외 좀비 스폰은 멈추고 기존 야외 좀비는 정리된다(복귀 시 재개).

### 5.1 플레이어
- 스탯: 최대체력, 이동속도, 픽업범위, 전체 데미지 배율, 공격속도 배율.
- 레벨업: 경험치 누적 → 레벨업 시 시간정지 + 강화 카드 3장 중 1개 선택.

### 5.2 좀비(적)
- MVP 1~2종:
  - **일반 좀비**: 저체력, 저속, 다수 스폰.
  - **러너 좀비**(여유 시 추가): 저체력, 고속.
- 시간 경과에 따라 체력/스폰율 증가.
- 사망 시 경험치 젬 드롭.

### 5.3 무기
- MVP 1~2종:
  - **군용 소총(기본)**: 가장 가까운 좀비에게 직선 투사체 자동 발사.
  - **대검(여유 시 추가)**: 플레이어 주변 근접 범위 회전 공격.
- 강화 카드로 데미지/발사속도/투사체 수 등 성장.

### 5.4 강화(레벨업 카드) — 5종 중 3택 랜덤
| 강화 | 효과 |
|---|---|
| 공격력 증가 | 무기 데미지 +15% |
| 공격 속도 증가 | 발사 주기 -10% |
| 이동속도 증가 | 이동속도 +10% |
| 체력 회복 | 최대체력의 30%만큼 즉시 회복 (최대치 자체는 증가하지 않음) |
| 아이템 획득 범위 증가 | 경험치 획득(자석) 범위 +20% |

레벨업마다 위 5종 중 서로 다른 3개를 무작위로 뽑아 카드로 제시한다. 최대 체력 증가형 강화는 없음 — 대신 즉시 회복형 강화로 생존력을 보완한다.

## 6. 밸런스 초안 (수치는 플레이테스트로 조정)

- 플레이어 최대체력: 100
- 플레이어 이동속도: 4 (유닛/초)
- 일반 좀비 체력: 10, 이동속도: 2, 접촉 데미지: 5(초당)
- 소총 데미지: 5, 발사 주기: 0.5초
- 경험치 커브: 레벨업 필요 XP = `4 + (level-1) * 3` (1레벨 4개 → 2레벨 7개 → 3레벨 10개 ... 선형 증가)
- 스폰 주기: 시작 1.5초 → 시간 경과에 따라 점진적으로 단축(하한선 존재, 0에 수렴하지 않도록 클램프), 좀비 체력/데미지도 시간에 비례해 무한 증가
- 생존 목표 시간: 없음(무한). HUD 타이머는 기록용으로만 계속 증가

## 7. 범위 (MVP vs 이후)

- **이번 MVP**: 핵심 루프 1회 완주 가능한 최소 구성 (docs/Roadmap.md 참고)
- **이후 확장**: 보스, 다양한 무기/시너지, 메타 성장(영구 강화), 다중 스테이지, 사운드/이펙트, 메인메뉴·결과창 UI
