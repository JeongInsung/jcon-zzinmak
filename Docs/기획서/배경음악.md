# 메인 메뉴 배경음악 (BGM)

## 개요
- **작업 씬**: `Assets/Scenes/2 SCENE.unity`
- **범위**: 메인 메뉴 안에서만 도는 루프 BGM 1곡 추가. `Intro`/`Game` 씬으로의 지속(persist)은 포함하지 않음 — 프로젝트에 씬 간 오디오를 유지하는 장치(`DontDestroyOnLoad`, AudioMixer 등)가 전혀 없고, `Game.unity`는 다른 담당자 영역이라 이번 범위 밖
- **제작 방식**: 새 루트 GameObject(`BGM`)를 Hierarchy에 직접 배치하고 `AudioSource` + `BgmPlayer` 컴포넌트만 부착

## 오디오 에셋
- `Assets/Sound/MenuBGM.mp3` (사용자 제공, 원본 `top-flow-suspense-567297_[cut_47sec] (1).mp3`을 정리한 파일명으로 복사, 길이 46.6초, 스테레오 48kHz)
- 임포터 설정: `loadType = CompressedInMemory`, `compressionFormat = Vorbis`, `quality = 0.7`, `forceToMono = false`, `loadInBackground = true`
- 클릭음(`button02b.mp3`, 모노/PCM/DecompressOnLoad)과 반대 방향 설정 — 짧은 UI 효과음과 긴 루프 음악은 성격이 다름

## 컴포넌트 구성
- `Assets/Scripts/UI/BgmPlayer.cs` (namespace `Zzinmak.UI`): 씬 시작 시 1.5초에 걸쳐 페이드인하며 루프 재생. `Update()`에서 "페이드 진행도(`fadeLevel`)"와 "설정창의 BGMVolume(PlayerPrefs)"을 매 프레임 곱해 최종 볼륨을 낸다 — 설정창에서 슬라이더를 드래그하면 즉시 반영됨
- `BGM`은 `Main Camera`/`Canvas`/`EventSystem`/`Map`/`InteriorRoom`과 같은 레벨의 **새 루트 오브젝트**. `Canvas`(이미 UI 인프라 + `MainMenuController`)에 얹지 않고 분리해 관심사를 나눔

## 씬 전환 시 페이드아웃
- `MainMenuController.LoadGameScene()`에 `bgmPlayer` 필드를 추가, 씬 전환 시작 시 `bgmPlayer.FadeOut()`을 호출해 `ScreenFader`의 0.6초 화면 페이드아웃과 동시에 음악도 조용해지게 함 (씬 언로드로 `AudioSource`가 파괴되며 소리가 뚝 끊기는 것을 방지 — 지난 클릭음 작업과 같은 이유)
- `QuitGame()`은 건드리지 않음 — 종료 시엔 화면 자체가 사라지므로 음악 페이드의 체감 효과가 없음

## BGMVolume 연동
- 설정창의 `SettingsController`가 지금까지 `"BGMVolume"` PlayerPrefs를 쓰기만 하고 아무도 읽지 않던 것을 `BgmPlayer.Update()`에서 처음으로 소비함 (`respectBgmVolumePref` 토글로 끌 수 있음)
- 이후 마스터 볼륨이 추가되면서 `"MasterVolume"`도 같이 곱해짐 — 자세한 내용은 `설정창.md` 참고
- 이로써 `설정창.md`의 TODO "실제 BGM/SFX 오디오 소스와 슬라이더 값 연동"이 완료됨 (SFX는 `버튼_피드백.md`에서 이미 완료)
- **범위 밖**: `SettingsController` 자체는 수정하지 않음. `AudioMixer`, `AudioListener.volume` 배선은 여전히 없음

## 설정값
- `baseVolume = 0.6` (설정 슬라이더가 최대일 때의 최대 볼륨, 인스펙터에서 조절 가능)
- `fadeInDuration = 1.5`초, `fadeOutDuration = 0.6`초 (`ScreenFader`의 페이드아웃과 맞춤)

## 알려진 이슈 / 주의
- Intro → 2 SCENE → Game 전환 전체에 걸친 BGM 지속은 없음 — 각 씬은 독립적으로 자기 오디오만 갖는다
- 이 프로젝트에는 여전히 AudioMixer가 없어서, BGM/SFX 간 상대적 밸런스는 각 컴포넌트의 `baseVolume`/`volume` 필드로만 조절함
