# 아이템 도감 (Item Codex)

## 개요
- **작업 씬**: `Assets/Scenes/2 SCENE.unity` (메인메뉴), 코드 훅은 `Assets/Scripts/Progression/ItemSelectionManager.cs`
- **구성**: 메인메뉴 "도감" 버튼 → 9칸 3x3 그리드(획득한 아이템은 아이콘+이름, 미획득은 회색 실루엣+"???") → 타일 클릭 시 상세 팝업(아이콘/이름/설명)
- **제작 방식**: UGUI, Hierarchy에 직접 구성 (Canvas 하위 `ItemCodexPanel`/`ItemDetailPopup`)

## 배경
게임 씬에는 이미 "아이템" 시스템이 있다 — 건물 내부 미니보스를 잡으면 가방(`Assets/Prefabs/가방.prefab`)이 드롭되고, 주우면 `ItemSelectionManager`가 9종의 `ItemData` 중 3개를 보여줘 하나를 고르게 한다. 이 중 3종(야간투시경/레이저사이트/던전탐지기)은 이미 영구 효과가 있어 PlayerPrefs로 저장되지만, 나머지 6종(응급처치키트/경험치키트/화력강화/공속강화/기동력강화/군용조끼)은 그 판에만 적용되고 "획득한 적 있음" 기록이 없었다.

도감을 만들려면 9종 전부에 "한 번이라도 획득했는가" 기록이 필요해서, 그 부분을 먼저 추가했다.

## 신규 코드

### `Assets/Scripts/Data/ItemCollection.cs`
아이템별 "최초 획득 여부"를 `PlayerPrefs`에 기록/조회하는 정적 헬퍼.
```csharp
PlayerPrefs.GetInt("ItemCollected_" + item.name, 0) == 1   // IsUnlocked
PlayerPrefs.SetInt("ItemCollected_" + item.name, 1)        // MarkCollected
```
키는 `item.name`(에셋 파일명, 예: `Item_HealthPotion`)을 쓴다 — `itemName`(한글 표시용)보다 안정적이고, 프로젝트가 이미 에셋명 기반 키(`BestSurvivalTime` 등)를 쓰는 관례에 맞춘다.

이 플래그는 기존 3종의 영구 효과 재적용 플래그(`Item_LaserSightUnlockedKey` 등, `ItemSelectionManager.cs:16-19`)와는 **별개 관심사**다 — 저건 "효과가 다음 판에도 유지되는가", 이건 "도감에 한 번 등록됐는가"를 나타낸다. 3종은 이제 플래그를 두 개씩(효과용 + 도감용) 갖게 된다.

### `Assets/Scripts/Progression/ItemSelectionManager.cs:112-116`
`ApplyItem(ItemData item)` 맨 앞에 한 줄 추가:
```csharp
private void ApplyItem(ItemData item)
{
    ItemCollection.MarkCollected(item);
    switch (item.type)
    ...
```
9종 전부가 실제로 선택되는 순간(가방→3개 중 1개 픽) 균일하게 기록된다.

### `Assets/Scripts/UI/ItemCodexController.cs`
메인메뉴 도감 패널에 부착. `items`/`tileButtons`/`tileIcons`/`tileLabels` 4개의 길이-9 배열을 인스펙터에서 순서대로 연결(0=응급처치키트 … 8=던전탐지기, `Game.unity`의 `ItemSelectionManager.allItems` 순서와 동일).
- `OnEnable`(메인메뉴로 돌아올 때마다 재실행): 각 아이템의 `ItemCollection.IsUnlocked` 결과에 따라 아이콘 색(흰색/회색), 라벨(실명/"???"), 버튼 `interactable`(획득 여부)을 갱신.
- 타일 클릭 → `ShowDetail0()`~`ShowDetail8()`(인자 없는 래퍼, 프로젝트의 다른 모든 버튼과 동일한 안전한 onClick 패턴) → 상세 팝업에 아이콘/이름/설명 표시.
- 잠긴 타일은 `interactable = false`라 클릭 자체가 막힌다 — 상세 팝업에 별도 "잠김" 상태를 그릴 필요가 없다.

## 씬 구성

```
Canvas
├── ItemCodexPanel        [기본 비활성] Image(백드롭) + UIPanelToggle(자기 자신) + ItemCodexController
│   └── ItemCodexCard     780x1040, roundRect8px
│       ├── ItemCodexTitle       TMP "아이템 도감"
│       ├── ItemGrid             GridLayoutGroup(CellSize 220x220, Spacing 20x20, FixedColumnCount 3)
│       │   └── ItemTile_0..8    Button + Image(배경) + Icon(자식 Image) + Label(자식 TMP "???")
│       └── ItemCodexBackButton  → 자기 UIPanelToggle.Close
└── ItemDetailPopup       [기본 비활성] Image(백드롭) + UIPanelToggle(자기 자신)
    └── ItemDetailCard    640x620, roundRect8px
        ├── DetailIcon         Image
        ├── DetailTitle        TMP
        ├── DetailDescription  TMP (Wrapping ON)
        └── DetailCloseButton  → 자기 UIPanelToggle.Close
```

`MenuButtons`에 다섯 번째 버튼 `CodexButton`("도감") 추가 → onClick: `ItemCodexPanel`의 `UIPanelToggle.Open`.

`MenuBackHandler.closablePanels`에 `ItemDetailPopup`, `ItemCodexPanel`을 등록(배열 뒤쪽 — 뒤로가기가 나중에 열린 패널을 먼저 닫도록). 우선순위: 상세 팝업 → 도감 → 최고기록 팝업 → 설정/크레딧 → 없으면 종료 확인창.

## 함께 마무리한 것: 최고기록 버튼 복구
직전 작업(최고 기록을 버튼으로 만들고 클릭 시 팝업을 띄우는 작업)이 씬 편집 도중 끊겨서, `MainMenuInfo`의 필드 연결이 깨지고(`bestRecordText`라는 이제 존재하지 않는 키가 남아 있었음) `BestRecordButton`의 onClick이 비어 있었다. 이번 작업 맨 앞에서 `BestRecordPopup`(제목+큰 시간 텍스트+닫기 버튼)을 완성하고 `MainMenuInfo`의 실제 필드(`bestRecordButtonLabel`/`bestRecordPopupText`)에 재배선했다.

## 후속 수정 — 미획득 아이템 표시 방식 (2026-08-11)
기존에는 미획득 타일도 아이콘 스프라이트를 어두운 색(`LockedTint`, 0.18/0.18/0.2)으로 tint해서 보여줬는데, 이게 아이템 모양이 비치는 "그림자"처럼 보였다. 타일 배경(9개 전부)을 순색 검정(`{0,0,0,1}`)으로 바꾸고, `ItemCodexController.OnEnable`에서 미획득 아이템은 `tileIcons[i].enabled = false`로 아이콘 자체를 꺼서 배경의 검은 자리가 그대로 빈 칸처럼 보이게 했다. 획득하면 `enabled = true` + 실제 스프라이트로 그 자리를 채운다. `LockedTint` 필드는 제거.
