# 메인 메뉴 (Main Menu)

## 개요
- **작업 씬**: `Assets/Scenes/2 SCENE.unity`
- **범위**: 화면 구성(레이아웃) + 시작/설정/종료/크레딧 버튼 전환 로직.
- **제작 방식**: UGUI. 스크립트로 생성하지 않고 Hierarchy에 실제 GameObject로 구성 (에디터에서 직접 수정 가능).
- **사용 에셋**: `Assets/Assets/UI Elements` 스프라이트 키트 (Extras/Rects, 아이콘)
- **폰트**: `Assets/Fonts/KMU80HaeongSemiSans SDF (Menu).asset` — 아래 "PF스타더스트"는 이후 이 폰트로 전면 교체됐다(`크레딧.md` 참고).

> 이 문서는 최초 작성 이후 실제 씬과 어긋난 부분이 있었다(배경 타일맵 없음, Background가 불투명, 타이틀이 실제 텍스트로 채워짐, spacing 값 변경 등). 아래는 현재 실제 상태로 갱신한 내용이다. 레이아웃 근본 수정 작업 내역은 [[메인메뉴_레이아웃_정리]] 참고.

## 계층 구조 (Hierarchy, 현재 상태)

```
2 SCENE
├── Main Camera
├── Canvas                 (Canvas, CanvasScaler[1080x2340], GraphicRaycaster, MainMenuController, MenuBackHandler, MainMenuInfo)
│   ├── Background         (Image, 화면 전체 stretch, dsa.png, 완전 불투명)
│   ├── SafeArea           (SafeArea 스크립트, 전체 스트레치 — 노치 대응)
│   │   ├── Title          (TMP "특수임무구조", 상단 중앙, 골드 그라디언트)
│   │   ├── MenuButtons    (VerticalLayoutGroup, 화면 중앙)
│   │   │   ├── StartButton    (Image=roundRect8px, Button, ButtonFeedback)
│   │   │   │   └── Label      (TMP "시작")
│   │   │   ├── SettingsButton (Image=roundRect8px, Button, ButtonFeedback)
│   │   │   │   ├── Label      (TMP "설정")
│   │   │   │   └── Icon       (Image=settings.png, 좌측 배치)
│   │   │   ├── QuitButton     (Image=roundRect8px, Button, ButtonFeedback, "종료") — onClick: QuitConfirmPanel.Open
│   │   │   │   └── Icon       (Image=cross.png, 좌측 배치)
│   │   │   └── CreditsButton  (Image=roundRect8px, Button, ButtonFeedback, "크레딧") — 자세한 내용은 `크레딧.md`
│   │   ├── BestRecordText (TMP, 타이틀 하단 — MainMenuInfo가 PlayerPrefs["BestSurvivalTime"]로 갱신)
│   │   └── VersionText    (TMP, 우측 하단 — MainMenuInfo가 Application.version으로 갱신)
├── SettingsPanel           (기본 비활성) — 자세한 내용은 `설정창.md`
├── CreditsPanel            (기본 비활성) — 자세한 내용은 `크레딧.md`
├── QuitConfirmPanel        (기본 비활성, CreditsPanel과 동일 구조 — 백드롭+카드+메시지+예/아니오 버튼)
│   └── QuitCard
│       ├── QuitMessage     (TMP "게임을 종료할까요?")
│       ├── QuitYesButton   (onClick: MainMenuController.QuitGame)
│       └── QuitNoButton    (onClick: QuitConfirmPanel.Close)
├── FadeOverlay             (전체 화면 검정, CanvasGroup + ScreenFader) — 씬 시작 시 검정→투명 페이드인
├── EventSystem            (EventSystem, InputSystemUIInputModule)
├── Map / InteriorRoom      (게임 맵 프리팹 인스턴스 — Background에 가려 화면에는 안 보임. 정리 대상, [[메인메뉴_레이아웃_정리]] 참고)
└── BGM                    (AudioSource + BgmPlayer)
```

`MenuBackHandler`는 Escape 키(안드로이드 뒤로가기)를 감지해 `SettingsPanel`/`CreditsPanel` 중 열려 있는 걸 먼저 닫고, 없으면 `QuitConfirmPanel`을 연다. `MainMenuInfo`는 씬이 활성화될 때마다 최고 기록과 버전 텍스트를 갱신한다.

**배경 타일맵(`MenuBackgroundGrid`)은 실제로 만들어지지 않았다.** 대신 `Background`가 `dsa.png` 불투명 이미지로 전체를 덮고, 그 뒤에 (보이지 않는) 게임 맵 프리팹이 얹혀 있다. alpha 0.4 반투명 계획과 spacing 24는 실제로 적용되지 않았다.

`Assets/Scripts/UI/ScreenFader.cs`가 `FadeOverlay`의 `CanvasGroup.alpha`를 1→0으로 페이드해, Intro의 검정 페이드아웃과 자연스럽게 이어지도록 한다.

## Canvas 설정
- Render Mode: Screen Space - Overlay
- CanvasScaler: UI Scale Mode = Scale With Screen Size, Match = 0.5, **Reference Resolution 1080x2340**(Game/Intro와 통일 완료). 이전에는 1920x1080(가로)으로 남아있어 설정창 뒤로가기 버튼 이탈 등 여러 배치 버그의 근본 원인이었음 — 수정 내역은 [[메인메뉴_레이아웃_정리]] 참고.
- `Canvas` 밑에 `SafeArea` 컨테이너 추가, `Title`/`MenuButtons`/최고기록·버전 텍스트가 그 안에 있음(노치 대응).

## 버튼 스타일
- 배경 스프라이트: `Assets/Assets/UI Elements/Extras/Rects/roundRect8px.png` (Image Type = Sliced, 9-slice border 포함)
- 크기: 480 x 90 (VerticalLayoutGroup이 폭은 늘리고 높이는 개별 유지)
- 라벨: TextMeshPro (PF스타더스트), 폰트 크기 36, 진한 회색 텍스트
- 아이콘 버튼(설정/종료)은 좌측에 아이콘(48x48 / 40x40) 배치

## 폰트 처리
- 프로젝트에 TMP 폰트 에셋이 전혀 없어 `Window > TextMeshPro > Import TMP Essential Resources`로 기본 리소스를 임포트함.
- 기본 LiberationSans는 한글을 지원하지 않아, 사용자가 제공한 `PF스타더스트 3.0.ttf`로 TMP Font Asset(`Assets/Fonts/PFStardust SDF.asset`, Dynamic 모드)을 생성해 제목/라벨에 적용함.

## 사용한 스프라이트
| 용도 | 경로 |
|---|---|
| 버튼 배경 | `Assets/Assets/UI Elements/Extras/Rects/roundRect8px.png` |
| 설정 아이콘 | `Assets/Assets/UI Elements/White/1x/settings.png` |
| 종료 아이콘 | `Assets/Assets/UI Elements/White/1x/cross.png` |
| 배경 이미지 | `Assets/Assets/dsa.png` (사용자 제공) |

> 참고: 키트의 `Button A/B/C.png`는 실제로는 알파벳 워터마크 그래픽이라 버튼 배경으로 부적합해 사용하지 않음. 순수 도형인 `Extras/Rects` 시리즈로 대체함.
