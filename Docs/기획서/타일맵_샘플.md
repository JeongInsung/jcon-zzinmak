# SF_Outside_A5 샘플 맵

## 개요
- **결과물**: `Assets/Modern City Street by Yanmby Project/Modern City Street by Yanmby/img/tilesets/SF_Outside_A5 Sample Map.prefab`
- **목적**: 사용자가 직접 슬라이스하고 만든 `SF_Outside_A5` 타일 팔레트(`tile.prefab`)를 실제로 써서 만든 작은 데모 맵. Game 씬은 친구가 작업 중이라 건드리지 않고, 별도 프리팹으로 분리해서 만들었음.
- **크기**: 12 x 8 칸 (Grid Cell Size 1x1)

## 구조
- `tile.prefab`(팔레트 자체)는 **건드리지 않았음** — 붓(브러시) 소스로 계속 사용 가능
- 새 프리팹에 Grid + Tilemap(`Layer1`) + TilemapRenderer를 새로 만들어 배치

## 레이아웃
- 테두리(가장자리 한 칸): 완전 검정 타일(빈 공간/벽처럼 보임)
- 맨 아래 안쪽 한 줄: 회색 통풍구/줄무늬 바닥 (복도처럼)
- 나머지 안쪽 영역: 청록색 회로 패턴 바닥 2종을 체커 무늬로 채움 (SF 시설 느낌)
- 중앙: 빛나는 핑크 육망성(헥사그램) 타일 2칸 — 제단/텔레포터 같은 포인트
- 여기저기: 붉은 "감염된" 유기질 텍스처, 이끼 낀 자국 타일을 소량 흩어 배치 (좀비 게임 분위기에 맞는 디테일)

이 배치는 타일셋 PNG를 직접 잘라서 미리 확인한 뒤 좌표 계산으로 배치한 것 — 유니티 에디터에서 실제로 보면서 다듬은 게 아니므로, 열어서 어색한 부분은 Tile Palette + 붓으로 바로 덧칠해 고치면 됨.

## Game 씬에 합치는 방법
1. Unity에서 이 프리팹을 더블클릭(Prefab 모드) 또는 Project 창에서 확인
2. 실제 게임에 쓰려면: 이 프리팹을 원하는 씬의 Hierarchy로 드래그 → Prefab 연결을 끊고(Unpack) 위치/좌표를 게임에 맞게 조정
3. 또는 이 프리팹의 `Layer1` Tilemap을 참고해서 기존 Game 씬의 Tilemap에 같은 타일들을 붓으로 옮겨 그리기
