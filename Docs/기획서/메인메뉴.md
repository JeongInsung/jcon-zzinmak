# 메인 메뉴 (Main Menu)

## 개요
- **작업 씬**: `Assets/Scenes/2 SCENE.unity`
- **범위**: 화면 구성(레이아웃)까지만. 버튼 클릭 시 실제 동작(게임 시작/설정 열기/종료)은 아직 연결되지 않음.
- **제작 방식**: UGUI. 스크립트로 생성하지 않고 Hierarchy에 실제 GameObject로 구성 (에디터에서 직접 수정 가능).
- **사용 에셋**: `Assets/Assets/UI Elements` 스프라이트 키트 (Extras/Rects, 아이콘)
- **폰트**: `PF스타더스트 3.0` (사용자 제공, `Assets/Fonts/PF스타더스트 3.0.ttf`)

## 계층 구조 (Hierarchy)

```
2 SCENE
├── Main Camera
├── Canvas                 (Canvas, CanvasScaler, GraphicRaycaster)
│   ├── Background         (Image, 화면 전체 stretch, 어두운 남색 단색)
│   ├── Title              (TextMeshPro "GAME TITLE", 상단 중앙)
│   └── MenuButtons        (VerticalLayoutGroup, 화면 중앙, spacing 24)
│       ├── StartButton    (Image=roundRect8px, Button)
│       │   └── Label      (TMP "시작")
│       ├── SettingsButton (Image=roundRect8px, Button)
│       │   ├── Label      (TMP "설정")
│       │   └── Icon       (Image=settings.png, 좌측 배치)
│       └── QuitButton     (Image=roundRect8px, Button)
│           ├── Label      (TMP "종료")
│           └── Icon       (Image=cross.png, 좌측 배치)
└── EventSystem            (EventSystem, InputSystemUIInputModule)
```

## Canvas 설정
- Render Mode: Screen Space - Overlay
- CanvasScaler: UI Scale Mode = Scale With Screen Size, Reference Resolution 1920x1080, Match = 0.5 (Width/Height 균형)

## 버튼 스타일
- 배경 스프라이트: `Assets/Assets/UI Elements/Extras/Rects/roundRect8px.png` (Image Type = Sliced, 9-slice border 포함)
- 크기: 480 x 90 (VerticalLayoutGroup이 폭은 늘리고 높이는 개별 유지)
- 라벨: TextMeshPro (PF스타더스트), 폰트 크기 36, 진한 회색 텍스트
- 아이콘 버튼(설정/종료)은 좌측에 아이콘(48x48 / 40x40) 배치

## 폰트 처리
- 프로젝트에 TMP 폰트 에셋이 전혀 없어 `Window > TextMeshPro > Import TMP Essential Resources`로 기본 리소스를 임포트함.
- 기본 LiberationSans는 한글을 지원하지 않아, 사용자가 제공한 `PF스타더스트 3.0.ttf`로 TMP Font Asset(`Assets/Fonts/PFStardust SDF.asset`, Dynamic 모드)을 생성해 제목/라벨에 적용함.

## 사용한 스프라이트
| 용도 | 경로 |
|---|---|
| 버튼 배경 | `Assets/Assets/UI Elements/Extras/Rects/roundRect8px.png` |
| 설정 아이콘 | `Assets/Assets/UI Elements/Black/1x/settings.png` |
| 종료 아이콘 | `Assets/Assets/UI Elements/Black/1x/cross.png` |

> 참고: 키트의 `Button A/B/C.png`는 실제로는 알파벳 워터마크 그래픽이라 버튼 배경으로 부적합해 사용하지 않음. 순수 도형인 `Extras/Rects` 시리즈로 대체함.
