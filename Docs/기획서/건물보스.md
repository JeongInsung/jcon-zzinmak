# 건물 미션 보스 (Building Mission Boss)

## 개요
- **관련 시스템**: `Assets/Scripts/Environment/MissionManager.cs` (건물 미션 루프), `Assets/Scripts/Enemies/` (Enemy/BossZombie/BossSpawner/BossProjectile/BossHealthBar)
- **목적**: 현재 건물 인터리어는 일반 좀비(`zombieCountPerBuilding`, 기본 5마리)만 전멸시키면 인질을 구출할 수 있다. 여기에 **보스 3종을 추가**하여, 건물에 들어갈 때마다 3종 중 1종이 랜덤으로 등장하는 미니보스전으로 만든다.
- **기존 보스와의 관계**: 현재 `BossSpawner.cs`가 야외 맵에서 플레이어 레벨 구간(`levelInterval`)마다 스폰하는 보스(`BossZombie`, `Assets/Data/Enemy_BossZombie.asset`)가 이미 있다. 이건 **야외 무한 난이도 상승용 보스**이고, 이번에 설계하는 건 **건물 인터리어 전용 미니보스 3종**으로 별개의 풀(pool)이다. 야외 보스와 이름이 겹치지 않게 아래 3종은 각각 다른 `EnemyData`/프리팹을 쓴다.

## 등장 규칙
- 건물 미션 입장(`MissionManager.EnterBuilding()`) 시:
  1. 기존과 동일하게 일반 좀비 웨이브를 스폰한다(수량은 보스 등장을 감안해 기본 5→**3마리로 축소** 조정 제안 — 보스 체력바까지 겹치면 인터리어가 너무 빡빡해질 수 있음. 최종 수치는 플레이테스트로 조정).
  2. 3종 보스 중 **랜덤 1종**을 인터리어 중심 부근에 추가로 1마리 스폰한다.
  3. 보스도 일반 좀비와 동일하게 `interiorZombies` 리스트에 포함시켜, **보스 포함 모든 개체가 죽어야 `interiorCleared = true`**가 되도록 한다(별도 조건 분기 불필요 — 기존 `Update()`의 카운트다운 로직을 그대로 재사용).
- **난이도 스케일링 없음**: `Docs/Architecture.md`에 명시된 기존 원칙("인터리어 좀비는 야외 난이도 스케일링과 무관한 고정 난이도")을 그대로 따른다. 건물 보스도 항상 체력 배율 1(고정 스탯)로 등장 — 몇 번째 건물인지와 무관하게 매번 동일한 난이도.
  - (확장 백로그) 추후 "건물 클리어 횟수"를 세어 보스 체력/데미지를 아주 완만하게 누적 증가시키는 옵션은 가능하나, 이번 MVP 범위에서는 제외.
- **연속 등장 방지(선택)**: 직전 건물과 같은 보스가 연달아 나오지 않도록 "마지막에 나온 보스 제외 후 랜덤" 방식을 권장(3종이라 완전 배제해도 선택지 2개가 남아 다양성 확보에 문제 없음).

## 보스 3종 설계

### 공통 사항
- 모두 기존 `Enemy.cs`(체력/이동/접촉데미지/사망 처리) + `EnemyData`(ScriptableObject) 기반. 콜라이더는 기존 원칙대로 **Trigger**.
- 모두 `BossHealthBar`를 사용해 화면에 체력바 표시(기존 `BossZombie`와 동일한 UI 재사용).
- 사망 시 일반 좀비보다 훨씬 큰 경험치 젬 보상(`expReward`)을 지급해 "보스를 잡을 가치"를 부여.
- 이동/공격 로직은 각각 전용 스크립트(`BossXxx.cs`)로 분리하고, 기존 `BossZombie.cs`의 구조(Enemy 이벤트 구독 + Animator 상태 전환 + 공격 중 `CanMove=false`)를 그대로 따른다.

### 보스 A — 도살자 (Butcher) *(기존 BossZombie 재사용)*
- **컨셉**: 근접 강타 + 원거리 침 뱉기를 섞는 만능형. 이미 구현되어 있는 `BossZombie.cs`/`BossProjectile.cs`/`Assets/character/boss zombie` 애니메이션(Walk/Attack1/Attack2/Die)을 그대로 사용.
- **패턴**: 근거리(≤1.5)에서는 근접 강타(20뎀), 중거리(2~7)에서는 침 발사체(12뎀). 플레이어가 거리 조절로 공격 패턴을 회피/유도하는 재미.
- **역할**: 3종 중 "정석형" — 밸런스 기준점.

### 보스 B — 질주자 (Sprinter) *(신규)*
- **컨셉**: 평소엔 빠르게 접근만 하다가, 주기적으로 **돌진(Dash) 공격**을 예고 동작 후 직선으로 꽂아 넣는 근접 전담형. 원거리 공격 없음 — 대신 이동속도가 3종 중 가장 빠름.
- **아트**: 신규 스프라이트/애니메이션 없이 시작하려면 `Assets/character/뛰는 좀비`(runzombie 프레임) 세트를 스케일 업(`localScale` 확대)해 재활용 가능. 다만 공격 모션(돌진 예고/타격) 프레임이 없으므로, 최소한 "예고 시 색상 강조(예: 빨갛게 Flash)" 같은 코드 연출로 대체하거나, 별도 돌진 애니메이션 제작이 필요.
- **패턴**:
  - 평상시: `moveSpeed`가 일반 좀비의 약 1.5배로 직선 추적.
  - 플레이어가 사거리(예: 6) 안에 들어오면 **0.6초 예고**(제자리 정지 + 강조 이펙트) 후, 플레이어가 예고 시점에 있던 방향으로 **짧고 빠른 돌진**(고정 거리, 관통 없음) — 돌진 중 충돌 시 큰 데미지(예: 25뎀) + 약한 넉백.
  - 돌진 종료 후 재사용 대기시간(쿨다운) 동안은 일반 추적만 함 → 플레이어 입장에서 "예고 보고 옆으로 피하기" 패턴 형성.
- **역할**: 근접 회피 스킬을 요구하는 "긴장감형" 보스. 체력은 낮은 대신 데미지가 셈(글래스 캐넌).

### 보스 C — 감염 숙주 (Broodmother) *(신규)*
- **컨셉**: 스스로는 느리고 약하지만 **주기적으로 일반 좀비를 소환**해 물량으로 플레이어를 압박하는 소환형. "잡몹 관리" 재미를 추가.
- **아트**: `Assets/character/Tank Zombie` 또는 `Assets/character/ZOMBIE2` 스프라이트를 스케일 업해 임시로 재활용(덩치 큰 느낌). 소환 이펙트는 간단한 파티클/색상 펄스로 대체 가능.
- **패턴**:
  - 이동속도 3종 중 가장 느림, 접촉 데미지도 가장 낮음.
  - 주기적으로(예: 8초마다) 자신 주변 반경에 기존 `Zombie` 프리팹(=`Enemy_Zombie` 데이터, 인터리어와 동일 고정 난이도)을 2~3마리 추가 소환. 소환된 좀비도 `interiorZombies` 리스트에 편입되어 클리어 조건에 포함됨(플레이어가 방치하면 좀비 수가 계속 불어나므로 방치 불가).
  - 근접 공격은 약한 할퀴기 정도만 보유(직접 위협보다는 "빨리 처치해야 소환이 멈춘다"는 압박이 핵심).
- **역할**: DPS 체크 + 잡몹 대처 능력을 시험하는 "물량형" 보스. 체력은 3종 중 가장 높음.

## 밸런스 초안 (플레이테스트로 조정)

| 항목 | 도살자(A, 기존) | 질주자(B) | 감염숙주(C) |
|---|---|---|---|
| 체력 | 300 | 220 | 380 |
| 이동속도 | 0.6 | 3.2 (평상시) | 0.4 |
| 접촉 데미지 | 15 | 10 | 8 |
| 특수 공격 데미지 | 근접 20 / 원거리 12 | 돌진 25 | 소환(데미지 없음) |
| 공격 쿨다운 | 근접 2.5s / 원거리 3.5s | 돌진 4s (예고 0.6s) | 소환 주기 8s (2~3마리) |
| 처치 경험치(`expReward`) | 50 | 40 | 60 (소환 다 처리해야 하는 리스크 보상) |

- 3종 모두 인터리어 고정 난이도 원칙에 따라 위 수치가 곧 최종 스탯(체력배율 항상 1).
- 소환숙주(C)가 계속 좀비를 늘리는 특성상, "소환 최대 유지 마리수 상한"(예: 동시에 8마리 이상이면 그 텀은 소환 스킵)을 코드 단에서 안전장치로 둘 것.

## 시스템 연동 변경 사항 (구현 시 참고)
- `MissionManager.cs`:
  - `[SerializeField] private GameObject[] bossPrefabs`(3개), `[SerializeField] private EnemyData[] bossData`(3개) 또는 보스별 프리팹 안에 데이터를 직접 물려서 배열 하나로 단순화(프리팹+데이터 쌍을 담은 작은 struct 권장).
  - `SpawnInteriorZombies()` 안에서 좀비 웨이브 스폰 후, 랜덤 인덱스로 보스 1종을 추가 스폰하고 `interiorZombies.Add(bossObj)`.
  - 직전 보스 인덱스를 기억해 연속 등장 방지(선택 사항).
- 신규 스크립트 2개: `BossSprinter.cs`(가칭), `BossBroodmother.cs`(가칭) — 둘 다 `[RequireComponent(typeof(Enemy))]` + `Enemy.OnDeath`/`OnHealthChanged` 구독 패턴은 `BossZombie.cs`와 동일하게 유지.
- 신규 데이터 에셋: `Assets/Data/Enemy_BossSprinter.asset`, `Assets/Data/Enemy_BossBroodmother.asset` (기존 `Enemy_BossZombie.asset`과 동일한 `EnemyData` 타입).
- 신규 프리팹: `Assets/Prefabs/BossSprinter.prefab`, `Assets/Prefabs/BossBroodmother.prefab`.
- 소환숙주(C)가 좀비를 소환할 때도 `ObjectPool.Instance.Get(zombiePrefab, ...)` + `Enemy.Initialize(zombieData, player, 1f)`를 그대로 재사용하면 되므로 새 풀링 로직은 불필요.
