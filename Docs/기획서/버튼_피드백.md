# 버튼 클릭 사운드 + 눌림 피드백

## 개요
- **작업 씬**: `Assets/Scenes/2 SCENE.unity`
- **범위**: 메인 메뉴 버튼 6개에 클릭 사운드 + 눌림(스케일 축소) 피드백 추가
- **제작 방식**: UI를 새로 만들지 않음. 이미 Hierarchy에 있는 버튼 GameObject에 컴포넌트(`AudioSource`, `ButtonFeedback`)만 부착
- **Game 씬 미접촉**: `Assets/Scenes/Game.unity`는 다른 담당자가 작업 중이라 이번 범위에서 제외. 단, 컴포넌트에 씬 참조를 두지 않아 버튼을 그대로 복사해 가도 동작한다

## 사운드 에셋
- `Assets/Sound/button02b.mp3` (사용자 제공, `Downloads`에서 복사, 길이 0.79초)
- 임포터 설정: `forceToMono = true` (UI 클릭이라 2D), `loadType = DecompressOnLoad` + `compressionFormat = PCM` (짧은 효과음이라 디코딩 히컵 없이 즉시 재생), `loadInBackground = false` (첫 클릭이 무음이 되지 않도록)

## 컴포넌트 구성
- `Assets/Scripts/UI/ButtonFeedback.cs` (namespace `Zzinmak.UI`): `IPointerDownHandler`/`IPointerUpHandler`/`IPointerExitHandler`로 클릭음 재생 + 스케일 트윈을 한 컴포넌트에서 처리
- 버튼과 같은 GameObject에 `AudioSource`(`playOnAwake=false`, `spatialBlend=0`, `PlayOneShot` 전용)를 같이 둔다
- **싱글톤 없음**: 클립은 에셋 참조, 재생은 자기 GameObject의 `AudioSource`를 사용하므로 다른 씬으로 복사-붙여넣기해도 그대로 동작한다 (`ScreenFader`/`UIPanelToggle`과 같은 결의 소형 컴포넌트)

### 적용 대상 6개
| 이름 | 경로 |
|---|---|
| StartButton | `Canvas/MenuButtons/StartButton` |
| SettingsButton | `Canvas/MenuButtons/SettingsButton` |
| QuitButton | `Canvas/MenuButtons/QuitButton` |
| CreditsButton | `Canvas/MenuButtons/CreditsButton` |
| BackButton | `Canvas/SettingsPanel/Panel/controler/BackButton` |
| CreditsBackButton | `Canvas/CreditsPanel/CreditsCard/CreditsBackButton` |

### 설정값
- `pressedScale = 0.95` (누르는 동안 5% 작아짐), `pressDuration = 0.06`, `releaseDuration = 0.12`
- 기준 스케일은 `Awake()`에서 한 번만 캡처해 상대값으로 트윈 (버튼마다 부모 `VerticalLayoutGroup`의 스케일이 달라 `Vector3.one` 고정값을 쓰지 않음)
- `Time.unscaledDeltaTime` 사용 (`ScreenFader.FadeRoutine`과 동일한 이유 — 일시정지 중에도 동작)

## 씬 전환 시 사운드 끊김 처리
- `StartButton` → `SceneManager.LoadScene`이 같은 프레임에 AudioSource를 파괴해 0.79초 클립이 잘리는 문제가 있었음
- 이미 존재하지만 안 쓰이던 `Assets/Scripts/UI/ScreenFader.FadeOutAndLoad(sceneName)`(0.6초 검정 페이드아웃)를 경유하도록 `MainMenuController.LoadGameScene()`을 수정 — `screenFader` 필드가 할당돼 있으면 위임, 없으면 `clickSoundDelay`만큼 기다린 뒤 즉시 로드
- **`FadeOverlay` GameObject가 씬에서 `m_IsActive: 0`으로 꺼져 있던 것을 다시 활성화함** — 꺼진 채로는 `ScreenFader`의 코루틴이 시작되지 않아 시작 버튼이 아무 반응 없이 죽는다. 활성화로 원래 기획(메인메뉴.md의 "씬 시작 시 검정→투명 페이드인")이 복구됨
- `QuitButton`은 페이드 없이 `clickSoundDelay = 0.85`초(클립 길이 기준) 지연 후 종료
- `StartButton`의 `onClick` 배선 자체는 건드리지 않음 (여전히 `MainMenuController.LoadGameScene` 호출)

## SFXVolume 연동
- 설정창의 `SettingsController`가 지금까지 `"SFXVolume"` PlayerPrefs를 쓰기만 하고 아무도 읽지 않던 것을, `ButtonFeedback.PlayClick()`에서 재생 볼륨에 곱해 처음으로 소비함 (`respectSfxVolumePref` 토글로 끌 수 있음)
- 이후 마스터 볼륨이 추가되면서 `"MasterVolume"`도 같이 곱해짐 — 자세한 내용은 `설정창.md` 참고
- **범위 밖**: `AudioMixer`, `AudioListener.volume` 배선은 여전히 없음

## 알려진 이슈 / 주의
- `MenuButtons`/`SettingsPanel`/`CreditsCard`의 `VerticalLayoutGroup`은 전부 `Child Scale Width/Height`가 꺼져 있어 `localScale` 트윈이 레이아웃과 충돌하지 않는다. **누군가 나중에 이 옵션을 켜면 눌린 버튼이 형제 버튼을 밀어내기 시작하므로 주의**
- 키보드/게임패드 Submit 이벤트는 대응하지 않음 (6개 버튼 모두 `Navigation = None`이라 현재는 무관)
- `Game.unity`의 버튼 6개는 이번 작업에 포함되지 않음
