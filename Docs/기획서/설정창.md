# 설정 창 (Settings Panel)

## 개요
- **작업 씬**: `Assets/Scenes/2 SCENE.unity`
- **구성**: 마스터 음량 슬라이더, BGM 음량 슬라이더 + 끄기 체크박스, 효과음(SFX) 음량 슬라이더 + 끄기 체크박스, 뒤로가기 버튼
- **제작 방식**: UGUI, Hierarchy에 직접 구성 (Canvas 하위 `SettingsPanel`)

## 계층 구조

```
Canvas
└── SettingsPanel      (Image 반투명 백드롭, 기본 비활성화, SettingsController)
    └── Panel          (Image 카드 배경, 720x1170)
        ├── SettingsTitle  (TMP "설정")
        ├── MasterLabel / MasterSlider   (Slider, 0~1) — BGM/SFX 위에 위치, 전체 음량. 체크박스 없음
        ├── BGMLabel / BGMSlider / BgmMuteToggle   (Slider 0~1 + "끄기" 체크박스)
        ├── SFXLabel / SFXSlider / SfxMuteToggle  (Slider 0~1 + "끄기" 체크박스)
        └── BackButton         (Button, "뒤로")
```

`MasterLabel`/`MasterSlider`는 `BGMLabel`/`BGMSlider`를 복제해서 만듦. `BgmMuteToggle`/`SfxMuteToggle`은 Unity 기본 `UnityEngine.UI.Toggle`(체크박스, `DefaultControls.CreateToggle` API로 생성 — `GameObject > UI > Toggle` 메뉴와 동일한 결과)을 새로 만들어 120x45로 리사이즈. 체크 표시(Checkmark)는 Unity 기본 스프라이트(`UI/Skin/Background.psd`, `UI/Skin/Checkmark.psd`) 그대로 사용, 라벨 텍스트만 "끄기"로 바꿈. 위에 한 행을 끼워넣기 위해 `SettingsTitle`을 위로, `Panel`의 높이를 900→1170으로 키움(아래쪽 고정, 위쪽만 확장). `BGMLabel/BGMSlider/SFXLabel/SFXSlider`의 위치는 건드리지 않음.

**참고**: 처음엔 `BackButton`을 복제한 작은 버튼(끄기/켜기 텍스트 토글)으로 만들었다가, 사용자 요청으로 체크박스(`Toggle`)로 교체함. 버튼 방식은 `AudioSource`+`ButtonFeedback`이 딸려와 클릭음이 자동으로 붙었지만, `Toggle`은 클릭음 컴포넌트가 없음 — 필요하면 `BgmMuteToggle`/`SfxMuteToggle`에도 `AudioSource`+`ButtonFeedback`을 추가하면 된다.

## 동작
- **설정 버튼**(메인 메뉴) 클릭 → `SettingsController.Open()` → `SettingsPanel` 활성화
- **뒤로 버튼** 클릭 → `SettingsController.Close()` → `SettingsPanel` 비활성화
- 슬라이더 값은 `PlayerPrefs`("MasterVolume", "BGMVolume", "SFXVolume")에 저장됨
- 스크립트: `Assets/Scripts/UI/SettingsController.cs` (namespace `Zzinmak.UI`)

## 마스터 볼륨
- `MasterVolume`(PlayerPrefs, 기본값 1)은 `BgmPlayer`와 `ButtonFeedback` 양쪽에서 각자의 볼륨 계산에 추가로 곱해진다:
  - `BgmPlayer.Update()`: `volume = fadeLevel * baseVolume * bgmPref * masterPref`
  - `ButtonFeedback.PlayClick()`: `v = volume * sfxPref * masterPref` (0 이하면 재생 자체를 건너뜀)
- 별도의 AudioMixer/AudioListener.volume 연동은 아님 — 각 컴포넌트가 PlayerPrefs를 직접 읽어 자기 볼륨에 곱하는 방식으로, 기존 BGM/SFX 연동과 동일한 패턴을 그대로 확장한 것

## BGM/SFX 끄기 체크박스
- `BgmMuteToggle`/`SfxMuteToggle` (`UnityEngine.UI.Toggle`) — 각 슬라이더 오른쪽에 위치한 체크박스. 체크 = 음소거. 마스터에는 체크박스 없음(요청 범위: 효과음 + BGM만)
- 체크하면: 현재 슬라이더 값을 `"{BGM|SFX}VolumePreMute"`에 백업 → 실제 볼륨 값(`"BGMVolume"`/`"SFXVolume"`)을 0으로. 슬라이더는 `SetValueWithoutNotify(0)`으로 0까지 따라가지만 `onValueChanged`는 발생하지 않음(중복 처리 방지)
- 체크 해제하면: 백업해둔 값을 복원
- 음소거된 상태에서 **슬라이더를 직접 드래그하면 자동으로 체크가 해제**된다(`OnBgmVolumeChanged`/`OnSfxVolumeChanged`에서 `value > 0`이면 `SetIsOnWithoutNotify(false)`로 체크 해제) — 사용자가 슬라이더를 만졌는데 소리가 계속 안 나는 혼란을 방지
- 음소거 상태(`"BGMMuted"`/`"SFXMuted"`, PlayerPrefs 0/1)는 앱을 껐다 켜도 유지됨
- `BgmPlayer`/`ButtonFeedback` 쪽 코드는 전혀 수정하지 않음 — 이미 읽고 있던 `"BGMVolume"`/`"SFXVolume"` 값이 0이 되는 것으로만 인지하므로, "음소거"라는 개념 자체를 몰라도 된다
