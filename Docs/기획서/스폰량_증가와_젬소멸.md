# 야외 좀비 스폰량 레벨 스케일링 + 경험치 젬 소멸 타이머

## 개요
- **관련 스크립트**: `Assets/Scripts/Enemies/EnemySpawner.cs`, `Assets/Scripts/Progression/ExpGem.cs`
- **목적**: 레벨이 오를수록 화면에 좀비가 더 많이 몰아쳐야 "성장하는 만큼 위협도 커진다"는 체감이 살고, 안 주운 경험치 젬이 맵에 무한히 쌓이는 것도 방지한다.

## 변경 1 — 좀비 스폰량 레벨 스케일링 (`EnemySpawner.cs`)
- 기존에는 한 번의 스폰 타이머(`CurrentSpawnInterval()`)마다 항상 좀비 1마리만 스폰했다. 시간 경과에 따라 스폰 **간격**만 짧아졌지, 한 번에 나오는 **마릿수**는 늘지 않았음.
- 이제 **플레이어 레벨**을 기준으로 한 번에 스폰하는 마릿수 자체가 계단식으로 늘어난다.
  - `levelsPerSpawnCountIncrease = 5`: 5레벨 오를 때마다 1단계 증가
  - `spawnCountIncreasePerStep = 1`: 한 단계당 +1마리
  - `baseSpawnCount = 1`: 1~5레벨 구간 기본 마릿수
  - `maxSpawnCountPerTick = 8`: 한 번에 너무 많이 몰아쳐서 프레임이 튀는 걸 막는 상한선(안전장치). 인터벌 감소에 이미 `minSpawnInterval` 하한선이 있는 것과 동일한 원칙.
  - 계산식: `tier = (레벨 - 1) / 5`, `스폰마릿수 = clamp(1 + tier * 1, 1, 8)` → 1~5레벨: 1마리, 6~10레벨: 2마리, 11~15레벨: 3마리 ... 36레벨 이후로는 8마리 고정(상한).
- 마릿수가 늘어도 스폰 위치는 각자 독립적으로 랜덤(플레이어 주변 반경 위에 무작위 각도)이라 한 지점에 겹쳐 나오지 않는다.
- 오브젝트 풀링을 그대로 재사용하므로 마릿수가 늘어도 `Instantiate/Destroy` 비용은 없음.

## 변경 2 — 경험치 젬 소멸 타이머 (`ExpGem.cs`)
- 좀비가 죽고 드롭된 경험치 젬을 플레이어가 줍지 않고 방치하면, **5초 뒤 자동으로 풀에 반환(소멸)**된다.
- `lifetime = 5f` 필드 추가, `OnEnable()`(풀에서 꺼내질 때마다 호출)에서 타이머를 초기화 → 재사용 시에도 항상 정확히 5초부터 다시 카운트.
- 픽업 범위 안에 들어와 플레이어 쪽으로 이동 중이던 젬도 5초를 넘기면 그대로 소멸(흡수 판정보다 소멸 타이머가 우선) — 스폰량 증가로 인해 젬이 화면에 계속 누적되는 것을 막기 위한 조치.

## 밸런스 참고
- 두 수치(5레벨/5초) 모두 사용자가 요청한 값 그대로 기본값으로 반영했다. 플레이테스트 후 `levelsPerSpawnCountIncrease`, `maxSpawnCountPerTick`, `ExpGem.lifetime` 인스펙터 값만 조정하면 재조율 가능.
