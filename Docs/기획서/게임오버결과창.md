# 게임오버 결과창 (Game Over Result Panel)

## 개요
- **작업 씬**: `Assets/Scenes/Game.unity`
- **목적**: 플레이어 사망(`GameEvents.OnGameOver`) 시 생존 시간/처치 수/최고 기록을 요약해 보여주고, 다시 시작 또는 메인 메뉴로 돌아가는 선택지를 제공한다. 이 게임은 무한 생존(엔딩 없음) 컨셉이므로 "승리 화면"은 없고, 이 결과창이 매 런의 유일한 종료 화면이다.
- **제작 방식**: UGUI. 스크립트로 생성하지 않고 Hierarchy에 직접 GameObject로 구성.
- **폰트**: `Assets/Fonts/Dalmoori SDF.asset` (Game.unity의 다른 텍스트와 동일)
- **버튼 배경**: `Assets/Assets/UI Elements/Extras/Rects/roundRect8px.png` (메인 메뉴와 톤 통일)

## 계층 구조 (Hierarchy)

```
Canvas                          (GameOverController 부착 — 항상 활성)
└── GameOverPanel                (Image 반투명 검정 백드롭 a=0.75, 화면 전체 stretch, 기본 SetActive(false))
    └── Panel                    (Image 800x900 카드 배경, 짙은 남색, roundRect8px Sliced)
        ├── Title                (TMP "게임 오버")
        ├── SurvivalTimeText     (TMP "생존 시간  00:00")
        ├── KillCountText        (TMP "처치 수  0")
        ├── BestTimeText         (TMP "최고 기록  00:00", 주황빛 강조색)
        ├── RestartButton        (Button + Label(TMP "다시 시작"))
        └── MainMenuButton       (Button + Label(TMP "메인으로"))
```

## 동작
- `GameOverController`는 **패널이 아니라 Canvas 루트**에 부착한다. `GameOverPanel`은 평소 비활성 상태라, 컨트롤러를 패널에 붙이면 `OnEnable` 구독이 걸리지 않아 `OnGameOver` 이벤트를 놓친다 — `SettingsController`와 달리 이 컨트롤러는 패널이 꺼져 있는 동안에도 이벤트를 미리 듣고 있어야 하므로, 항상 활성인 Canvas에 붙이고 패널을 `[SerializeField]`로 참조해 `SetActive(true)`로 켜는 방식을 취했다.
- **패배** → `PlayerHealth` → `GameManager.TriggerGameOver()` → `Time.timeScale = 0f` + `GameEvents.OnGameOver` 발행 → `GameOverController.HandleGameOver()`가 구독으로 수신.
- `HandleGameOver()`:
  - `GameManager.Instance.ElapsedTime`/`.KillCount`를 읽어 생존 시간(mm:ss)과 처치 수를 표시.
  - `PlayerPrefs`("BestSurvivalTime")와 비교해 최고 기록 갱신 여부를 판단, 갱신 시 저장 후 "NEW!" 표기.
  - `GameOverPanel.SetActive(true)`.
- **다시 시작 버튼** → `GameOverController.Restart()`: `Time.timeScale = 1f` 복구 후 `SceneManager.LoadScene("Game")`.
- **메인으로 버튼** → `GameOverController.ReturnToMainMenu()`: `Time.timeScale = 1f` 복구 후 `SceneManager.LoadScene("2 SCENE")`.
- 스크립트: `Assets/Scripts/UI/GameOverController.cs` (namespace `Zzinmak.UI`)
