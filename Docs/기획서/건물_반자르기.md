# 건물 반 자르기 (위/아래 스프라이트 분리)

## 작업 일자
2026-08-04

## 배경
`Assets/Map/Map.prefab`의 건물은 SpriteRenderer 하나로만 그려지면 플레이어가 건물 앞을 지나가도 늘 건물이 위에 그려지거나(또는 항상 아래), 항상 같은 앞뒤 관계로 보여 입체감이 없음. 기존 건물 대부분(예: `area2_건물_08 (경찰서)`)은 스프라이트를 위/아래 두 조각으로 잘라 서로 다른 Order in Layer를 줘서, 플레이어가 건물 아래쪽(1층/정문)을 지날 때는 건물 뒤로 가려지고, 건물 위쪽(옥상/상층부)을 지날 때는 건물 앞으로 나오게 만드는 깊이감을 낸다.

8월 3일에 추가된 폐허 스타일 건물 4채가 `area3 / 건물` 그룹에 한 줄로 임시 배치되어 있었는데, 아직 통짜 스프라이트(Order 0) 상태였음. 기존 건물들과 렌더링을 통일하기 위해 같은 방식으로 반 잘라 처리함.

## 규격 (패턴 A — 수직 오프셋 방식)

1536×1024px, PPU 100 건물 이미지를 예로 들면:

1. **텍스처 슬라이스**: `.meta`의 `spriteSheet.sprites`를 1×2 그리드로 나눔.
   - `_0` (원본 위쪽 절반, rect y=512~1024) — 기존 `_0` 스프라이트의 `internalID`/`spriteID`는 **그대로 유지**하고 rect만 위쪽 절반으로 축소. 이렇게 하면 이미 씬/프리팹에서 그 스프라이트를 참조하던 오브젝트를 건드릴 필요가 없음.
   - `_1` (아래쪽 절반, rect y=0~512) — 새로 추가. `alignment: 0`, `pivot: {0.5, 0.5}`.
2. **부모 GameObject** (기존 건물 오브젝트 그대로 재사용):
   - SpriteRenderer: `_0`(위쪽) 스프라이트, **`m_SortingOrder: 3`**, `m_Size.y`를 절반으로.
   - Transform: `m_LocalPosition.y`를 **`+ (원본 세로 크기의 1/4) × m_LocalScale.y`** 만큼 올림 — 슬라이스 후 `_0`이 자기 중심 피벗으로 다시 그려지면서 원래보다 반 칸 아래로 내려가 보이는 것을 보정.
     - 예: 전체 세로 10.24 유닛 건물 → 자식 조각 세로 5.12 → 보정값 `2.56 × scale.y`.
   - `m_Children`에 새 자식 추가.
3. **자식 GameObject** (신규):
   - SpriteRenderer: `_1`(아래쪽) 스프라이트, **`m_SortingOrder: 1`**, `m_Color`/`m_Size`는 부모와 동일하게 복사.
   - Transform: `m_LocalPosition = (0, -(조각 세로 크기), 0)`, `m_LocalScale = (1,1,1)`. **부모의 스케일과 무관하게 항상 조각 자체의 세로 크기(유닛)** 만큼만 내리면 이음새가 딱 맞음 (부모/자식 모두 같은 좌표계에서 스케일링되므로 상쇄됨).

공통 불변식: 두 SpriteRenderer 모두 `m_SortingLayerID/m_SortingLayer: 0`, `m_SpriteSortPoint: 0`, `m_DrawMode: 0`, Material은 `a97c105638bdf8b4a8650670310a4cd3` (Sprite-Lit-Default).

## 참고 / 주의
- **새 건물을 추가할 때 이 작업도 자동으로 안 됨** — `맵_그림자_시스템.md`의 ShadowCaster2D, `건물_콜라이더.md`의 fw 콜라이더와 같은 성격. 매번 수동으로 반복 필요.
- 이번 작업 범위는 **자르기(스프라이트 슬라이스 + 부모/자식 구조 + Order 3/1)까지만** — ShadowCaster2D와 `fw` 콜라이더는 포함하지 않음. 그림자/충돌은 Unity 에디터에서 기존 도구(`Zzinmak/건물 콜라이더 일괄 생성`)와 수동 ShadowCaster2D 추가로 이어서 처리할 것.
- 아직 맵에 배치되지 않은 8월 3일자 건물 이미지(병원 `03_31_33`, 소방서 `03_33_47-Photoroom` 등)는 이번 범위에 포함되지 않음.
- Unity 에디터가 열려 있는 상태에서 `Map.prefab`을 텍스트로 직접 편집하면 저장 시 덮어써질 수 있으므로, 이런 방식의 편집은 **항상 Unity를 완전히 종료한 뒤** 진행할 것.
