# 보스 방향 화살표 (Boss Direction Arrow)

## 개요
- **목적**: 보스가 등장했을 때(야외 레벨 보스든, 건물 인터리어 보스든) 플레이어가 어느 방향에 있는지 바로 알 수 있도록 HUD에 작은 화살표를 띄운다.
- **표시 조건**: 활성 보스가 하나라도 있으면 화살표가 보이고, 없으면 자동으로 숨는다. 여러 보스가 동시에 존재하는 경우(이론상 야외 보스 + 건물 보스 동시 발생) 플레이어와 가장 가까운 보스를 가리킨다.

## 동작 방식
- **`BossMarker.cs`** (`Assets/Scripts/Enemies/`): 보스 프리팹(BossZombie/BossSprinter/BossBroodmother 전부)에 부착된 자가 등록형 마커. `OnEnable`/`OnDisable`에서 정적 리스트에 자신을 등록/해제한다 — 오브젝트 풀링으로 재사용되는 보스도 `SetActive` 시점에 자동으로 등록/해제되므로 야외 스폰이든 건물 스폰이든 별도 연동 코드 없이 동일하게 추적된다.
- **`BossDirectionIndicator.cs`** (`Assets/Scripts/UI/`): `Canvas/HUD/BossArrowIndicator`에 부착. 매 프레임 `BossMarker.GetNearestActiveBoss()`로 가장 가까운 보스를 찾아, 플레이어 기준 방향 각도를 계산해 화살표 아이콘을 그 방향으로 회전시킨다. 보스가 없으면 화살표를 비활성화.
- 화살표는 씬 하이어라키에 직접 배치된 UI 오브젝트(`Canvas/HUD/BossArrowIndicator`)이고, 스크립트는 회전 값만 갱신한다(기존 UI 원칙 준수).

## 위치/비주얼
- HUD 상단 체력바 아래, 화면 중앙(`anchoredPosition (0, 800)`)에 배치. 조이스틱(좌하단)이나 레벨업 카드와 겹치지 않는 여유 공간.
- 아이콘은 `Assets/Art/Placeholder/boss_arrow.png` — 코드로 생성한 단색 삼각형 placeholder(오른쪽을 가리키는 기본 방향, 노란색 틴트). 실제 아트로 교체 시 이 스프라이트만 갈아끼우면 됨.
