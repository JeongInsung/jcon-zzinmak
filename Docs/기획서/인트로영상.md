# 인트로 영상 (Intro Splash)

## 개요
- **작업 씬**: `Assets/Scenes/Intro.unity` (신규 생성, Build Settings 첫 번째 씬)
- **목적**: 게임 실행 시 메인 메뉴가 뜨기 전에 영상을 재생하고, 검정 화면 전환 후 메인 메뉴(`2 SCENE`)로 넘어감
- **영상**: `Assets/Videos/기지 상공 접근 수정.mp4` (사용자 제공, 인코딩 1080x1080 + 픽셀비 9:16 → 실제 표시 9:16 세로, 길이 약 3초)
  - 이전 버전 `기지 상공 접근.mp4`도 프로젝트에 남아있음(비교/롤백용, 참조는 더 이상 안 함)

## 계층 구조 (Hierarchy)

```
Intro
├── Main Camera     (Camera, AudioListener, VideoPlayer, UniversalAdditionalCameraData)
│   └── VideoPlayer: clip=기지 상공 접근 수정.mp4, renderMode=Render Texture, aspectRatio=Stretch, playOnAwake=false(스크립트가 Prepare 후 Play), isLooping=false
├── FadeCanvas      (Canvas Screen Space-Overlay, CanvasScaler referenceResolution=1080x2340)
│   ├── VideoImage  (RawImage, 화면 전체 stretch. AspectRatioFitter는 붙어있지만 비활성) — VideoPlayer의 RenderTexture(1080x2340)를 표시
│   └── FadeImage   (Image, 화면 전체 stretch, 검정색, 시작 알파=0)
└── IntroManager    (IntroSequence 스크립트)
```

**URP 주의사항**: `VideoPlayer.renderMode = Camera Far/Near Plane`은 Built-in RP 전용 기능이라 URP에서는 아무것도 렌더링하지 않는다. 그래서 `Assets/Videos/IntroVideoRT.renderTexture`를 만들어 VideoPlayer의 `targetTexture`로 지정하고, `FadeCanvas/VideoImage`의 `RawImage`가 그 RenderTexture를 화면에 그린다.

### 화면 해상도(1080x2340) 맞춤 — 비율 불일치와 결정

목표 화면 해상도가 **1080x2340(9:19.5, 0.4615)** 으로 확정되면서, RenderTexture와 `CanvasScaler.referenceResolution`도 720x1280 → **1080x2340** 으로 올렸다.

문제는 영상 자체의 실제 비율이 **9:16(0.5625)** 이라 화면 비율(9:19.5)과 다르다는 점. 비율이 다른 두 영상/화면을 맞추는 방법은 근본적으로 3가지뿐이고, 트레이드오프가 있어 택1이 필요했다:

| 방식 | 결과 | 비고 |
|---|---|---|
| 가득 채우기(crop) | 좌우 약 9% 잘림, 왜곡 없음 | `AspectRatioFitter` 활성 + `EnvelopeParent` + ratio 0.5625 |
| **늘려서 채우기(stretch)** ✅ 채택 | 잘림/여백 없음, 세로로 살짝 늘어나는 왜곡 있음 | 아래 구현 방식 |
| 전체 보이기(letterbox) | 위아래 검은 띠, 왜곡 없음 | `AspectRatioFitter` + `FitInParent` |
| 영상 재인코딩 | 완벽히 맞음 | 유니티 밖(편집툴)에서 캔버스를 1080x2340로 다시 내보내야 함 |

**결정: "늘려서 채우기"**. 구현:
- `VideoImage`의 `RectTransform`은 anchor `(0,0)~(1,1)`, sizeDelta `(0,0)` — 화면 전체를 그냥 stretch로 채움
- `AspectRatioFitter`는 **비활성**(꺼둠) — 비율 보정을 하지 않아야 stretch가 그대로 적용됨
- `VideoPlayer`는 `renderMode = Render Texture`이므로 `aspectRatio` 필드는 실제 렌더에 영향 없음(Unity 특성). 다만 의도 표시용으로 `Stretch`로 맞춰둠
- 결과적으로 영상이 RenderTexture(1080x2340) 크기에 그대로 늘어나 채워지고, 그 텍스처가 화면 전체를 stretch로 덮는다

나중에 왜곡이 거슬리면 위 표의 "가득 채우기" 또는 "영상 재인코딩"으로 전환 가능. 가득 채우기로 바꿀 경우: RT를 1080x1920로 되돌리고, `AspectRatioFitter.enabled = true`, `mode = EnvelopeParent`, `ratio = 0.5625`로 설정.

## 동작 흐름
1. 씬 시작 시 `IntroSequence`가 `videoPlayer.playOnAwake = false`로 두고 직접 `Prepare()` 호출 → 디코더 초기화가 끝나면(`prepareCompleted`) `Play()` 호출. RenderTexture를 통해 `VideoImage`에 그려짐
   - `playOnAwake = true`로 즉시 재생하면 디코더 초기화 중에 첫 프레임(들)이 끊기는 "살짝 멈추는" 느낌이 생겼음. Prepare 완료 후 재생하도록 바꿔서 해결
2. 영상이 끝나면(`loopPointReached`) `IntroSequence.BeginTransition()` 호출 — **영상은 끝까지 재생됨** (중간에 강제로 끊지 않음)
3. `FadeImage`의 알파를 0→1로 1초에 걸쳐 서서히 올려 검정 화면 전환
4. 전환 완료 후 `SceneManager.LoadScene("2 SCENE")`으로 메인 메뉴 씬 로드

**스킵**: `Update()`에서 매 프레임 터치/마우스 클릭/키보드 입력(New Input System — `Touchscreen`, `Mouse`, `Keyboard`) 중 아무거나 눌리면 즉시 `BeginTransition()`을 호출해 영상 재생 여부와 무관하게 바로 넘어간다. 스킵도 정상 종료와 똑같이 페이드 전환을 거친다.

안전장치: `videoPlayer.errorReceived`로 로딩/재생 오류 시 즉시 스킵하고, 워치독 코루틴이 영상 길이 기준으로 타임아웃을 좁혀가며 어떤 이유로든 `loopPointReached`가 오지 않아도 씬이 무한 대기하지 않도록 보장한다(기본 상한 15초).

## 스크립트
- `Assets/Scripts/UI/IntroSequence.cs` (namespace `Zzinmak.UI`)
  - `videoPlayer`, `fadeImage`, `nextSceneName`("2 SCENE"), `fadeDuration`(1초), `safetyTimeout`(15초), `endMargin`(2초) 필드로 Inspector에서 조정 가능

## 에디터 편의 기능
- `Assets/Editor/PlayFromIntroScene.cs`: 메뉴 `Zzinmak/재생 시 항상 인트로부터 시작`(기본 켜짐)이 켜져 있으면, 에디터에서 어떤 씬을 열어두고 Play를 눌러도 항상 `Intro` 씬부터 시작한다(`EditorSceneManager.playModeStartScene`). 개발 중 Game 씬만 빠르게 반복 테스트하고 싶으면 이 메뉴를 꺼서 현재 씬에서 바로 재생할 수 있다. 설정은 `EditorPrefs`에 저장되어 에디터 재시작 후에도 유지된다.
- `ProjectSettings/EditorSettings.asset`의 **Enter Play Mode Options → Disable Domain Reload**를 켬(`m_EnterPlayModeOptions: 1`). Play 버튼을 누를 때마다 C# 도메인을 통째로 리로드하면서 생기던 시작 시 멈칫함을 줄이기 위함. **주의**: 도메인이 리로드되지 않으므로 스크립트의 `static` 필드 값이 Play를 껐다 켜도 초기화되지 않고 이전 값이 남아있을 수 있다 — 새 스크립트를 짤 때 static 상태에 의존한다면 `OnEnable`/`Start`에서 직접 초기화해야 한다. 씬 리로드(Disable Scene Reload)는 켜지 않았으므로 씬 자체는 Play마다 정상적으로 다시 로드된다.

## Build Settings
- 씬 순서: `Intro`(0) → `2 SCENE`(1) → `Game`(2)
- Intro가 0번이므로 빌드 실행 시 자동으로 가장 먼저 재생됨
- 에디터에서 Play 버튼은 기본적으로 **현재 열린 씬**에서 시작한다(빌드 인덱스와 무관) — 위 "에디터 편의 기능" 참고
