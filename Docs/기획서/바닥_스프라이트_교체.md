# 바닥 스프라이트 교체

## 요청

"바닥" 그룹(구 dirt 타일 576장 등) 안 모든 스프라이트를 `Assets/Map/바닥/땅.png`로 통일.

## 문제 — 크기 불일치

기존 dirt 타일 스프라이트는 320x320px(3.2유닛 @ 100PPU)인데, `땅.png`는 1254x1254px(12.54유닛 @ 100PPU)로 약 4배 크다. 게다가 Sprite Mode가 "Multiple"인데 실제 슬라이스는 이미지 전체를 덮는 1개뿐이라 사실상 단일 스프라이트다. 스프라이트만 그대로 교체하면 각 타일이 갑자기 4배 가까이 커져서 서로 심하게 겹치며 화면이 깨진다.

**해결(사용자 확인):** 스프라이트를 바꾸면서 각 타일의 `localScale`도 같이 조정해서 화면상 크기가 지금과 동일하게 유지되도록 한다.

## 수정

`Assets/Editor/GroundSpriteReplaceTool.cs` 추가. `Zzinmak/바닥 스프라이트를 땅.png로 교체` 메뉴로 실행.

- 대상: Map 루트의 `바닥` 그룹 자식들(없으면 `dirt*` 텍스처를 쓰는 SpriteRenderer 전체로 대체 탐색)
- 각 타일마다 `비율 = (기존 스프라이트 월드 크기) / (새 스프라이트 월드 크기)`를 각 축(x/y)별로 계산해서 `localScale`에 곱한다 — 이미 스케일이 조금씩 다른 타일(예: [[맵_하이러키_정리]] 조사에서 나온 24장의 `1.0226562`짜리)도 그 차이를 유지한 채 축소된다.
- `sr.sprite`를 교체 후 `localScale`을 갱신하므로, 두 번 실행해도 두 번째부터는 비율이 1이 되어 안전(멱등).

## 적용 시 주의

`Map.prefab`을 프리팹 모드로 열고 실행할 것. 적용 후 Scene 뷰에서 타일 크기가 이전과 같은지, 색/질감이 바뀐 것 외에 레이아웃이 그대로인지 확인하고 Ctrl+S로 저장.
