# 설정 창 (Settings Panel)

## 개요
- **작업 씬**: `Assets/Scenes/2 SCENE.unity`
- **구성**: BGM 음량 슬라이더, 효과음(SFX) 음량 슬라이더, 뒤로가기 버튼
- **제작 방식**: UGUI, Hierarchy에 직접 구성 (Canvas 하위 `SettingsPanel`)

## 계층 구조

```
Canvas
└── SettingsPanel      (Image 반투명 백드롭, 기본 비활성화, SettingsController)
    └── Panel          (Image 카드 배경, 700x650)
        ├── SettingsTitle  (TMP "설정")
        ├── BGMLabel / BGMSlider   (Slider, 0~1)
        ├── SFXLabel / SFXSlider  (Slider, 0~1)
        └── BackButton         (Button, "뒤로")
```

## 동작
- **설정 버튼**(메인 메뉴) 클릭 → `SettingsController.Open()` → `SettingsPanel` 활성화
- **뒤로 버튼** 클릭 → `SettingsController.Close()` → `SettingsPanel` 비활성화
- 슬라이더 값은 `PlayerPrefs`("BGMVolume", "SFXVolume")에 저장됨
- 스크립트: `Assets/Scripts/UI/SettingsController.cs` (namespace `Zzinmak.UI`)
