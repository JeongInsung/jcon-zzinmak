# 크레딧 화면 (Credits)

## 개요
- **작업 씬**: `Assets/Scenes/2 SCENE.unity`
- **구성**: 메인 메뉴에서 "크레딧" 버튼으로 열고, "뒤로" 버튼으로 닫는 오버레이 패널
- **제작 방식**: UGUI, Hierarchy에 직접 구성 (Canvas 하위 `CreditsPanel`), `Assets/Scripts/UI/UIPanelToggle.cs`로 열기/닫기만 처리
- **Game 씬 미접촉**: 이 작업은 친구가 작업 중인 `Assets/Scenes/Game.unity`를 건드리지 않기 위해 2 SCENE/Intro 범위에서만 진행함

## 계층 구조

```
Canvas
├── MenuButtons (VerticalLayoutGroup)
│   ├── StartButton / SettingsButton / QuitButton (기존)
│   └── CreditsButton      (Button, "크레딧") — onClick: CreditsPanel(UIPanelToggle).Open
└── CreditsPanel            (Image 반투명 백드롭, 기본 비활성, UIPanelToggle)
    └── CreditsCard         (Image 카드 배경, 720x1200, SettingsPanel과 동일한 roundRect8px 스타일)
        ├── CreditsTitle    (TMP "크레딧")
        ├── CreditsBody     (TMP, 플레이스홀더 본문 — 아래 TODO 참고)
        └── CreditsBackButton (Button, "뒤로") — onClick: CreditsPanel(UIPanelToggle).Close
```

## 스크립트
- `Assets/Scripts/UI/UIPanelToggle.cs` (namespace `Zzinmak.UI`): `[SerializeField] GameObject panel` 하나만 갖고 `Open()/Close()/Toggle()`이 `panel.SetActive(...)`만 호출하는 범용 토글. `SettingsController`처럼 전용 컨트롤러를 새로 만들지 않고, 이 패턴을 그대로 재사용해 회귀 위험 없이 패널을 추가했다.
- `CreditsPanel`의 `panel` 필드는 **자기 자신**을 참조한다(설정창의 `SettingsController.settingsPanel`도 동일 패턴).
